关于 Cache Hit Ratio
Prompt caching 通过重用已有上下文来减少 token 消耗。当 cache_read 越高，说明越多上下文被重用，hit ratio 越高，成本越低。
目前数据主要来自 Kimi API，其 OpenAI 兼容接口仅返回 cached_tokens 而不含 cache_write_tokens，因此 Cache Write 显示为 0。若使用 Anthropic API，则会同时记录 cache_creation_input_tokens。
